# The communication system turns deep reasoning into a clear journey

## Simple language carries the meaning before style carries the mood

Write for an ESL reader who should not need specialist vocabulary to follow the argument.

Use these defaults:

- Choose common words when they preserve the exact meaning.
- Define necessary jargon the first time it appears.
- Use active voice and name the actor.
- Put one main claim in each sentence.
- Keep most sentences short enough to read in one breath.
- Break a paragraph when the idea, evidence class, actor, or time changes.
- Replace vague praise with observable qualities.
- Keep the reasoning deep; simplify the language, not the truth.

Avoid consultant language such as “leverage synergies,” “best-in-class,” “north-star alignment,” or “transformative solution” unless quoting and examining a source.

Prefer:

| Avoid | Prefer |
| :---| :---|
| Seamless | Without repeating information, changing channels, or losing progress |
| Intuitive | People could proceed without help or repeated correction |
| Efficient | Required fewer steps, less time, less coordination, or less mental effort |
| Delightful | Produced a named and evidenced positive response |
| Improved | State what became better and how it was observed |
| Transformed | Describe the before-and-after system change |
| Ensured | Designed to, testing indicated, or verification showed |
| Users | Name the role, group, or behavior pattern |

## The parent-title path tells the story before the detail begins

For every substantial response or artifact, plan the H2 titles as a narrative spine.

The H2 sequence must answer, in order:

1. Where are we starting?
2. What did the evidence reveal?
3. What tension or decision follows?
4. What changed or should change?
5. What does the result mean?
6. What happens next?

The exact number of sections may vary. The titles must form a coherent continuum rather than a table of contents.

Run the **H2-only test**:

> If a reader sees only the H2 titles from top to bottom, can they understand the whole argument and its direction?

Weak sequence:

- Overview
- Research
- Strategy
- Features
- Results

Stronger sequence:

- The work began with a fragmented path to a high-stakes goal
- The evidence showed that delay came from the whole service, not one screen
- That changed the choice from digitizing forms to protecting progress
- A shared lifecycle then gave every actor a clear next step
- Release proved delivery, while live evidence set the limit of the outcome claim

Do not force every title to be a complete sentence. It must still advance the same story.

## Child titles reveal the reasoning that supports each turn

Make each H3 or H4 continue its parent’s thought. A child title should not feel transferable to any unrelated document.

Example:

> **Parent:** The evidence showed that delay came from the whole service, not one screen  
> **Child:** Handoffs made applicants repeat work they believed was complete  
> **Child:** Internal teams lacked one state model for the same request  
> **Child:** Policy limits ruled out a purely self-service answer

Run the **H2+H3 test**:

> If a reader sees only the parent and child titles, can they follow both the conclusion and the reasoning behind it?

Use plain labels inside compact utility areas only when narrative titles would slow use—for example, metadata fields, table columns, evidence codes, or form controls.

## Structure creates an attention-friendly reading rhythm

Use formatting when it reduces effort:

- H1 for the artifact title.
- H2 for the main narrative turns.
- H3 and H4 for supporting reasoning.
- Bullets for parallel items.
- Numbered lists for order, priority, or procedure.
- Tables for exact mappings, comparisons, status, and traceability.
- Quotes for a governing statement, user voice, or approved decision.
- Clear breaks when the story changes direction.

Keep table labels and content left-aligned. Keep cells brief and top-oriented by avoiding long mixed paragraphs. Move explanations below the table when they would make rows difficult to scan.

Do not force headings into a very short answer. Do not use a table for a single fact. Structure must serve meaning.

## Strategic emojis orient the reader without becoming decoration

Use an emoji only when it acts like a stable wayfinding symbol.

Suggested meanings:

| Symbol | Meaning |
| :---| :---|
| 🧭 | Orientation, scope, or direction |
| 🔎 | Evidence, investigation, or audit |
| ⚖️ | Choice, trade-off, or human decision |
| ⏸ | Required pause or approval gate |
| ✅ | Verified completion or passed check |

Rules:

- Use no emoji when the text is already easy to navigate.
- Use one symbol consistently for one meaning.
- Do not put an emoji on every heading.
- Do not use emojis as praise, filler, or visual confetti.
- Prefer none in formal artifacts when the audience or context calls for restraint.

## Evidence language stays visible as the narrative becomes persuasive

Story quality never overrides claim quality.

Keep these distinctions explicit:

- documented fact vs later reconstruction;
- project evidence vs external context;
- hypothesis vs decision;
- targeted vs designed vs released;
- validation within a test scope vs success in live operation;
- qualitative observation vs quantitative measurement;
- contribution vs causation; and
- personal work vs directed, shared, or team work;
- direct testimony vs a note-taker’s or stakeholder’s report;
- one speaker vs several speakers or a wider group; and
- reported belief vs observed behavior or measured change.

Keep these distinctions visible in the final sentence, not only in a private evidence ledger. Never compress “a product manager’s notes report that one supervisor believed…” into “staff observed…”.

Use dates or sequence markers for historical claims. Name missing evidence at the point where it limits the conclusion.

Use the universal component grammar as a reasoning check:

> **For [specific actor], in [relevant context], [level-specific proposition], because [evidence or strategic rationale], so that [relationship to the intended human outcome].**

The final prose does not need to repeat this full formula. The underlying reasoning must contain each applicable part.

## Every ending returns the reader to truth and forward motion

End a substantial output with the meaning of the result, not a generic summary.

Include the smallest useful combination of:

- what the evidence now supports;
- what remains unknown or disputed;
- what decision has been made;
- what decision still belongs to a human;
- what was excluded and why;
- what changes downstream; and
- what the next action or review gate is.

At a controlled checkpoint, state the number of remaining planned approvals when it is known. Never imply approval merely because a draft is complete.
