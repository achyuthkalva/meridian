# Meridian Research Source Index

This index is the canonical home for Meridian's research links. Supporting references link here with stable source IDs so each external research URL is maintained once.

> [!IMPORTANT]
> These sources support definitions, distinctions, methods, and quality controls. They do not prove what a historical project team knew, decided, built, or achieved.

## How to use this index

- Follow a source title to open the original publication.
- Link other Meridian references to the stable source anchor, not directly to the external URL.
- Recheck time-sensitive claims against the current primary source before publication.
- Preserve whether Meridian terminology is established, source-adapted, or playbook-synthesized.

## The index ends where project evidence begins

Use public research to explain a domain, method, or surrounding condition. Keep project provenance separate: a public source cannot establish a team's historical intent, chronology, ownership, or outcome without project evidence connecting it.
