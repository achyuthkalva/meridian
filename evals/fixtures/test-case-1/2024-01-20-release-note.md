# PermitPath release note

Date: 20 January 2024
Status: Published release note

PermitPath is live for new residential alteration permits in River County.

The live release includes resident submission and status tracking, the clerk work queue, missing-information requests, and the audit history. Payments and inspection scheduling are not included.

The county approved the release after operational readiness, security, accessibility, and design QA checks.

No post-release performance measures are included in this note.
